# VMware 虚拟机网络详解与配置
## 三种网络模式原理、特性、适用场景 
### 1.1  VMnet0：桥接模式（Bridged）
 虚拟机直接 “接入” 宿主机所在物理局域网，相当于局域网里一台独立电脑。  
● IP：由路由器 DHCP 分配，和宿主机同一个网段
虚拟机直接 “接入” 宿主机所在物理局域网，相当于局域网里一台独立电脑。  此模式下的虚拟机和自己的依赖主机共同处在同一个网段下，意思就是如果主机的IP是192.168.100.xxx,那么虚拟机中的IP地址也将会是192.168.100.xxx,虚拟机也会占用局域网中的一个IP地址。
● 虚拟机上网、宿主机访问虚拟机、局域网其他设备都能直接访问虚拟机
缺点： 换 WiFi / 换路由器网段会变；部分校园网、企业网会限制多设备，桥接会失效；需要占用路由器一个 IP  
### 1.2 VMnet1：仅主机模式（Host-Only）
 完全隔离外网，只有宿主机和所有使用 VMnet1 的虚拟机组成封闭内网。  
● IP：VM 内置 DHCP 分配，宿主机有虚拟网卡VMware Network Adapter VMnet1
● 虚拟机与宿主机互通，虚拟机之间互通
● 不能访问互联网
● 适用：内网安全测试、集群实验、病毒测试、完全隔离环境

### 1.3 VMnet8：NAT模式（Network Address Translation）
虚拟机处在 VMware 内部私有子网，通过宿主机做地址转换共享宿主机网卡上网。
● IP：VM 内置 DHCP 分配，网段独立，和宿主机物理网卡不是同一网段，宿主机有虚拟网卡VMware Network Adapter VMnet8
● 虚拟机可以访问外网、访问宿主机、同网段虚拟机互通
● 局域网其他设备无法主动访问虚拟机（需要配置端口转发）
● 优点：换网络环境（家里 / 公司 / WiFi 切换）不用改 IP，不容易断网，隔离性好
● 适用：Linux 开发、后端调试、上网测试（绝大多数开发场景首选）
NAT 高级配置：选中 VMnet8 →【NAT 设置】，可以修改网关、端口转发（把宿主机端口映射到虚拟机端口，外部访问虚拟机服务）；【DHCP 设置】修改 IP 地址池、租期。

### 1.4 三种模式对比
特性	NAT	桥接	仅主机
访问外网	✅	✅	❌
宿主机访问虚拟机	✅	✅	✅
局域网其他设备访问虚拟机	❌（需端口映射）	✅	❌
虚拟机 IP 来源	VMware 内置 DHCP	路由器 DHCP	VMware 内置 DHCP
网段	独立私有网段	和宿主机同网段	独立私有网段
换网络环境稳定性	高	低	不受外网影响
 虚拟机网卡配置（单台虚拟机）  
● 关闭虚拟机 → 【虚拟机】→【设置】→【网络适配器】
● 勾选：已连接、启动时连接
● 网络连接选择：NAT / 桥接 / 仅主机 / 自定义
● 确定后开机，虚拟机内配置 IP（DHCP 自动获取或静态 IP）
支持多网卡：添加多个网络适配器，一块 NAT 上网，一块仅主机做内网通信。
