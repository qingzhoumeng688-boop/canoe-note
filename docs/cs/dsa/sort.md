# 06 排序算法

> 本篇导读：排序是最经典的算法练习场。本篇把十大排序讲透：思想、稳定性、时间/空间复杂度，并重点拆解快排与归并的分治精髓，给出选型决策表。

## 一、排序基础

排序（Sorting）是把一组记录按某个关键字从小到大（或从大到小）排成有序序列。它是二分查找、归并、堆、数据库 ORDER BY 等一切"有序才能高效"操作的前置。先建立几个贯穿全篇的概念。

### 1.1 稳定性（Stability）

**稳定排序**：关键字相等的两条记录，排序后它们的**相对先后顺序不变**。例如原序列 `(3a, 1, 3b, 2)`（两个 3 用 a/b 区分先后），稳定排序后必是 `(1, 2, 3a, 3b)`，3a 仍在 3b 前。

为什么稳定性重要？当**多关键字排序**时（如"先按班级排，再按分数排"），常见做法是"对次级关键字稳定排序、再对主关键字稳定排序"。若排序不稳定，第一步的班级次序会被打乱。另外在对象排序中，相等键可能携带不同附属信息，保持原序避免无意义抖动。

### 1.2 内部排序 vs 外部排序

- **内部排序**：数据全部在内存中，比较/移动都在内存完成。本篇除"归并可用于外排序"外基本都是内部排序。
- **外部排序**：数据大到内存放不下，需借助磁盘，核心思路是"分块排序 + 多路归并"。归并排序是外排序的基石。

### 1.3 比较排序的下界 O(n log n)

所有**基于比较**的排序，决策过程可画成一棵决策树：每个内部节点是一次"比较两元素"，叶子是某一种排列结果。n 个元素有 `n!` 种排列，所以决策树至少 `n!` 个叶子。一棵高度为 `h` 的二叉树最多 `2^h` 个叶子，于是 `2^h ≥ n!`，取对数得 `h ≥ log(n!) ≈ n log n - n log e`，即**最坏比较次数下界为 `Ω(n log n)`**。

结论：**冒泡、选择、插入、希尔、快排、归并、堆排**都逃不出 `O(n log n)` 的最坏/平均比较下界（快排最坏 `O(n²)` 是退化，不在下界讨论内）。要突破 `O(n log n)`，必须**不比较**——这就是计数、桶、基数排序的思路（利用整数/分布特征）。

### 1.4 选型要权衡的因素

| 因素 | 影响 |
| --- | --- |
| 数据规模 `n` | 小 `n` 简单排序够用；大 `n` 必须用 `O(n log n)` 类 |
| 是否近乎有序 | 插入排序对近乎有序接近 `O(n)`；快排反而可能退化 |
| 稳定性要求 | 归并稳定、快排/选择/堆排不稳定 |
| 空间限制 | 堆排原地 `O(1)`；归并需 `O(n)`；快排递归栈 `O(log n)` |
| 数据特征 | 整数且范围小 → 计数；分布均匀 → 桶；定长整数 → 基数 |

### 1.5 两个常被问到的补充概念

- **原地排序（In-place）**：额外数据空间为 `O(1)`，只用常数个临时变量，如插入、选择、堆排、快排（递归栈视为调用开销，不计入"额外数据空间"）。归并需要 `O(n)` 临时数组，属于非原地。
- **自适应排序（Adaptive）**：输入越有序越快，如插入排序（最好 `O(n)`）、冒泡排序（加交换标志后最好 `O(n)`）；快排、堆排、归并的时间与输入有序度无关，是非自适应。

这两个维度叠加"稳定性""复杂度"，构成了一句话描述一个排序算法的完整画像。

## 二、简单排序

三种 `O(n²)` 的基础排序，思想朴素，是理解更复杂算法的地基。

### 2.1 冒泡排序（Bubble Sort）

相邻两两比较，逆序就交换，每轮把当前未排序区最大的"冒"到末尾。加一个"本轮是否发生交换"的标志可提前终止（已有序时 `O(n)`）。

```text
举例 [5, 2, 4, 1] 的轮次：
轮1: (5,2)->(2,5) (5,4)->(4,5) (5,1)->(1,5)  => [2,4,1,5]  (5 归位)
轮2: (2,4)ok (4,1)->(1,4)          => [2,1,4,5]  (4 归位)
轮3: (2,1)->(1,2)                  => [1,2,4,5]  (2 归位)
```

- 时间：平均/最坏 `O(n²)`，最好（已序）`O(n)`。
- 空间：`O(1)` 原地。
- 稳定：是（相等不交换）。

### 2.2 选择排序（Selection Sort）

每轮从"未排序区"选最小的，放到已排序区末尾。与冒泡不同，它**不在每步交换，而是每轮只交换一次**。

- 时间：无论数据如何都 `O(n²)`（哪怕已序也要扫完找最小）。
- 空间：`O(1)` 原地。
- 稳定：**否**（选最小与前方交换可能跨过相等元素，打乱次序）。

### 2.3 插入排序（Insertion Sort）

像摸牌：默认左手已排好，右手每摸一张，从右往左插入到正确位置。

```text
[5] 2 4 1
摸2: [2,5] 4 1
摸4: [2,4,5] 1
摸1: [1,2,4,5]
```

- 时间：平均/最坏 `O(n²)`；**最好（近乎有序）`O(n)`**，且常数极小。
- 空间：`O(1)` 原地。
- 稳定：是。
- 价值：小规模或近乎有序时常常**快过** `O(n log n)` 算法，所以快排/归并的小区间常"切到阈值改用插入排序"。

| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | `O(n²)` | `O(n²)` | `O(n)` | `O(1)` | 是 |
| 选择 | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | 否 |
| 插入 | `O(n²)` | `O(n²)` | `O(n)` | `O(1)` | 是 |

### 2.4 三种简单排序的 Java 实现

把思想落成代码，注意三者都就地、且只有插入与冒泡保持相等元素原序：

```java
package com.canoe.dsa.sort;

public class SimpleSorts {
    /** 冒泡：每轮把未排序区最大值冒到末尾，无交换则提前结束 */
    public void bubble(int[] a) {
        for (int i = 0; i < a.length - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < a.length - 1 - i; j++) {
                if (a[j] > a[j + 1]) { swap(a, j, j + 1); swapped = true; }
            }
            if (!swapped) break;
        }
    }

    /** 选择：每轮选未排序区最小值，与区间首位交换（跨位交换→不稳定） */
    public void selection(int[] a) {
        for (int i = 0; i < a.length - 1; i++) {
            int min = i;
            for (int j = i + 1; j < a.length; j++) {
                if (a[j] < a[min]) min = j;
            }
            swap(a, i, min);
        }
    }

    /** 插入：摸牌式，把 a[i] 插到左侧已排序区的正确位置 */
    public void insertion(int[] a) {
        for (int i = 1; i < a.length; i++) {
            int key = a[i], j = i - 1;
            while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
            a[j + 1] = key;
        }
    }

    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
}
```

## 三、希尔排序

**希尔排序（Shell Sort）**是插入排序的改进：先把数组按某个**增量 gap** 分成若干子序列，各自做插入排序；逐步缩小 gap 直到 1，最后做一次普通的插入排序。

为什么能突破 `O(n²)`？插入排序慢在"每次只挪一位"。gap 大时元素大跨步移动，能快速把小元素甩到前面、大元素甩到后面，让序列"基本有序"；到 gap=1 时，序列已近乎有序，插入排序退化为 `O(n)`。

- **gap 序列**：原始 Shell 用 `n/2, n/4, ..., 1`（最坏仍 `O(n²)`）；更优的如 **Knuth 序列 `1, 4, 13, 40...`（(3^k-1)/2）** 或 Sedgewick 序列，能把最坏压到约 `O(n^(3/2))` 甚至更好。一句话：**gap 序列的选择决定希尔排序的复杂度，没有单一最优序列。**
- 时间：依赖 gap，介于 `O(n log² n)` 到 `O(n^(3/2))` 之间。
- 空间：`O(1)` 原地。
- 稳定：**否**（跨 gap 的插入会打乱相等元素次序）。

### 3.1 希尔排序的 Java 实现

把插入排序的"步长恒为 1"换成 `gap`，每个子序列内部仍是插入排序，gap 减半直至 1：

```java
package com.canoe.dsa.sort;

public class ShellSort {
    public void sort(int[] a) {
        int n = a.length;
        for (int gap = n / 2; gap > 0; gap /= 2) {        // 原始 Shell gap 序列
            for (int i = gap; i < n; i++) {
                int key = a[i], j = i - gap;
                while (j >= 0 && a[j] > key) { a[j + gap] = a[j]; j -= gap; }
                a[j + gap] = key;
            }
        }
    }
}
```

把 `gap = n/2, n/4, ...` 换成 Knuth 或 Sedgewick 序列，可进一步压低最坏复杂度。

## 四、快速排序

**快速排序（Quick Sort）**是分治的典范，也是几乎所有语言内置 `sort` 的底层主力（往往与插入、堆排混合）。

### 4.1 思想

选一个**基准（pivot）**，把比它小的放左边、比它大的放右边（partition），这样 pivot 就落在了最终位置；再对左右两个子区间递归。关键操作是 `partition`。

### 4.2 partition（双指针）

常见写法：选最右元素为 pivot，维护一个 `i` 指针表示"小于区的右边界"，`j` 从左往右扫，`nums[j] < pivot` 就与 `i` 交换并 `i++`，最后把 pivot 换到 `i` 处。

```text
数组 [5, 3, 8, 2, 7, 1, 4]，选最右 4 为 pivot
i=-1, j 扫描：
 j=0 v=5 >4 跳过
 j=1 v=3 <4 -> i=0, 交换(3,5) => [3,5,8,2,7,1,4]
 j=2 v=8 >4 跳过
 j=3 v=2 <4 -> i=1, 交换(5,2) => [3,2,8,5,7,1,4]
 j=4 v=7 >4 跳过
 j=5 v=1 <4 -> i=2, 交换(8,1) => [3,2,1,5,7,8,4]
扫完，i=2，把 pivot 换到 i+1=3: 交换(5,4) => [3,2,1,4,7,8,5]
pivot(4) 归位到下标 3，左区 [3,2,1] 全<4，右区 [7,8,5] 全>4
```

```java
package com.canoe.dsa.sort;

public class QuickSort {
    public void sort(int[] a) {
        sort(a, 0, a.length - 1);
    }

    private void sort(int[] a, int lo, int hi) {
        if (lo >= hi) return;
        int p = partition(a, lo, hi);
        sort(a, lo, p - 1);
        sort(a, hi == p ? hi : p + 1, hi);
    }

    private int partition(int[] a, int lo, int hi) {
        int pivot = a[hi];
        int i = lo - 1;
        for (int j = lo; j < hi; j++) {
            if (a[j] < pivot) {
                i++;
                swap(a, i, j);
            }
        }
        swap(a, i + 1, hi);
        return i + 1;
    }

    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
}
```

### 4.3 复杂度与优化

- 时间：平均 `O(n log n)`（每层 partition `O(n)`，递归 `O(log n)` 层）；**最坏 `O(n²)`**——当每次 pivot 都是最大/最小（如已序数组选端点），退化成单边递归。
- 空间：递归栈 `O(log n)` 平均，`O(n)` 最坏；原地 `O(1)` 额外。
- 稳定：**否**（partition 跨位置交换会打乱相等元素）。
- **优化**：
  - **随机化 pivot**：随机选一个与端点交换，期望上避免最坏，实际几乎总 `O(n log n)`。
  - **三数取中**：取 `lo/mid/hi` 三者的中位数作 pivot，对近乎有序数据很稳。
  - **三路快排**：把相等的元素单独聚到中间，避免大量重复键时退化（如 `[2,2,2,...]`）。
  - **小数组切插入排序**：区间长度小于阈值（如 10~15）时改插入排序，减小常数。

### 4.4 快排的递归分解示意

一次 partition 后，原区间被 pivot 切成左右两半，递归像一棵二叉树向下展开，每片叶子长度为 0 或 1 即有序：

```text
          [5,3,8,2,7,1,4]
                pivot=4
         /                \
     [3,2,1]            [7,8,5]
      pivot=1            pivot=5
       /    \             /    \
     [ ]   [3,2]       [ ]    [8,7]
          pivot=2             pivot=7
           /   \               /   \
         [ ]  [3]            [ ]   [8]
```

整棵树的高度即递归深度：平均 `log n` 层、最坏（每次只减少一个元素）`n` 层——这正是快排最坏 `O(n²)` 的几何来源。

### 4.5 随机化 pivot 的实现要点

把"固定选最右作 pivot"改成"先随机挑一个与最右交换"，就能把人为构造的最坏输入（如已序数组）的期望复杂度拉回 `O(n log n)`：

```java
// 在原有 partition 之前加一行即可
int r = lo + rand.nextInt(hi - lo + 1);
swap(a, r, hi);     // 随机位置换到末尾，再走原 partition 逻辑
```

三数取中则是取 `lo`、`(lo+hi)/2`、`hi` 三者的中位数换到 `hi`，对"近乎有序"数据特别稳，是工程实现的首选。

## 五、归并排序

**归并排序（Merge Sort）**也是分治，但策略是"先分后合"：把数组对半拆到长度为 1，再两两**合并**成有序。

### 5.1 合并（merge）是关键

两个已排序的子数组，用双指针各取较小者放入临时数组，最后拷回。这是稳定操作。

```text
合并 [1,4,7] 与 [2,5,8]：
取 1 -> [1]
取 2 -> [1,2]
取 4 -> [1,2,4]
取 5 -> [1,2,4,5]
取 7 -> [1,2,4,5,7]
取 8 -> [1,2,4,5,7,8]
```

```java
package com.canoe.dsa.sort;

public class MergeSort {
    public void sort(int[] a) {
        int[] buf = new int[a.length];
        sort(a, buf, 0, a.length - 1);
    }

    private void sort(int[] a, int[] buf, int lo, int hi) {
        if (lo >= hi) return;
        int mid = (lo + hi) >>> 1;
        sort(a, buf, lo, mid);
        sort(a, buf, mid + 1, hi);
        merge(a, buf, lo, mid, hi);
    }

    private void merge(int[] a, int[] buf, int lo, int mid, int hi) {
        for (int k = lo; k <= hi; k++) buf[k] = a[k];
        int i = lo, j = mid + 1;
        for (int k = lo; k <= hi; k++) {
            if (i > mid) a[k] = buf[j++];
            else if (j > hi) a[k] = buf[i++];
            else if (buf[i] <= buf[j]) a[k] = buf[i++];  // <= 保证稳定
            else a[k] = buf[j++];
        }
    }
}
```

### 5.2 性质

- 时间：**最好/平均/最坏都是 `O(n log n)`**——分治层数固定 `log n`，每层合并 `O(n)`。这是它相对快排的优势：没有最坏退化。
- 空间：需 `O(n)` 临时数组（可优化但本质仍线性）。
- 稳定：是（`merge` 里 `buf[i] <= buf[j]` 取左，保序）。
- **外排序基础**：内存放不下时，可"每次读一块排好写回，再做多路归并"，归并天然适合顺序读写磁盘。

### 5.3 归并的分与合

归并是"先彻底分到底，再自底向上两两合并"：

```text
分：      [5,3,8,2,7,1,4]
        /            \
     [5,3,8]       [2,7,1,4]
     /    \        /     \
   [5]   [3,8]   [2,7]   [1,4]
          |        |       |
        [3][8]   [2][7]  [1][4]
合：   自下而上两两合并成有序子段，最终拼成整段：
       [3,8] -> [2,7] -> [1,4] -> [2,3,5,7,8] -> [1,2,3,4,5,7,8]
```

分给的层数固定 `log n`，每层的合并合计 `O(n)`，因此无论最好最坏都稳定在 `O(n log n)`。

## 六、堆排序

**堆排序（Heap Sort）**利用二叉堆（本篇默认大顶堆）：先 `O(n)` 建堆，再反复把堆顶（最大）与末尾交换、堆大小减 1、下沉调整，得到升序。

- **建堆 `O(n)`**：从最后一个非叶子节点自底向上 `siftDown`，数学上可证总代价 `O(n)` 而非 `O(n log n)`。
- **取堆顶 `O(log n)`**：每次交换后下沉恢复堆性质，共 `n` 次，故排序主体 `O(n log n)`。
- 时间：最好/平均/最坏 **`O(n log n)`**。
- 空间：**原地 `O(1)`**（只用常数交换）。
- 稳定：**否**（堆的跳跃式交换破坏次序）。
- 与 **Top-K** 关联：求前 K 大/小不必全排——用大小为 K 的堆扫描一遍 `O(n log K)` 即可，是堆排最经典的应用延伸（如"最大的 100 个数"）。

### 6.2 建堆与下沉（siftDown）

建堆从最后一个非叶子节点自底向上调用 `siftDown`（也叫 heapify）；每次取堆顶后把末尾换到顶，再 `siftDown` 把堆恢复。注意整段用大顶堆、循环取顶会得到升序。

```java
package com.canoe.dsa.sort;

public class HeapSort {
    public void sort(int[] a) {
        int n = a.length;
        for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n); // 建堆 O(n)
        for (int end = n - 1; end > 0; end--) {
            swap(a, 0, end);          // 堆顶(最大)换到当前末尾
            siftDown(a, 0, end);      // 缩小堆尺寸并下沉恢复
        }
    }

    private void siftDown(int[] a, int i, int n) {
        while (true) {
            int l = 2 * i + 1, r = 2 * i + 2, largest = i;
            if (l < n && a[l] > a[largest]) largest = l;
            if (r < n && a[r] > a[largest]) largest = r;
            if (largest == i) break;
            swap(a, i, largest);
            i = largest;
        }
    }

    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
}
```

`siftDown` 每次最多下沉 `log n` 层，单次 `O(log n)`；建堆虽调用 `n/2` 次，但越靠下的节点下沉距离越短，整体可证为 `O(n)`。

## 七、非比较排序

三者都**不依赖元素间比较**，利用"整数取值/分布/位数"等额外信息，达到线性 `O(n)`（但各有前提限制）。

### 7.1 计数排序（Counting Sort）

适用：**整数、且值域 `k` 不大**。开一个计数数组 `cnt[x]` 统计每个值出现次数，做前缀和得到"每个值该落在哪个位置"，从后往前填保证稳定。

- 时间：`O(n + k)`，k 为值域跨度。
- 空间：`O(n + k)`。
- 稳定：可做到稳定（逆序回填）。
- 局限：`k` 远大于 `n` 时（如排 10 个数却跨 0~10⁹）空间爆炸，不可用。

### 7.2 桶排序（Bucket Sort）

适用：**元素均匀分布在区间 `[0,1)` 或某范围**。把区间分成若干桶，元素按值落入对应桶，桶内各自排序（常递归用快排/插排），再按顺序拼接。

- 时间：均匀时 `O(n + k)`（k 为桶数），最坏（全落一桶）退化为桶内排序。
- 空间：`O(n + k)`。
- 稳定：取决于桶内所用算法。
- 局限：依赖分布均匀；分布偏斜时退化为桶内排序复杂度。

### 7.3 基数排序（Radix Sort）

适用：**定长整数/字符串**，按"位"从低到高（LSD，Least Significant Digit）或从高到低（MSD）逐位用稳定排序（通常计数排序）处理。每一轮只比较一位，共 `d` 轮（d 为位数）。

- 时间：`O(d · (n + k))`，d 为位数、k 为单个数基（如十进制 k=10）。
- 空间：`O(n + k)`。
- 稳定：**必须**用稳定子排序（否则高位排序会打乱低位结果），故常配合计数排序。
- 局限：要求"位"可分解；变长数据需补位或改用 MSD。

### 7.4 三者对比

| 算法 | 核心前提 | 时间 | 空间 | 稳定 | 典型场景 |
| --- | --- | --- | --- | --- | --- |
| 计数 | 整数、值域小 | `O(n+k)` | `O(n+k)` | 可稳定 | 年龄/分数/小范围枚举 |
| 桶 | 分布均匀 | `O(n)`（期望） | `O(n+k)` | 取决于子算法 | 均匀浮点、近似排序 |
| 基数 | 定长可分层 | `O(d(n+k))` | `O(n+k)` | 可稳定 | 手机号、定长字符串、IP |

## 八、复杂度总表

十种排序一张表收口（空间为额外空间，`n` 为大 O 记号）：

| 排序 | 平均时间 | 最坏时间 | 最好时间 | 额外空间 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 冒泡 | `O(n²)` | `O(n²)` | `O(n)` | `O(1)` | 是 | 可提前终止 |
| 选择 | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | 否 | 交换少、不稳定 |
| 插入 | `O(n²)` | `O(n²)` | `O(n)` | `O(1)` | 是 | 近乎有序极快 |
| 希尔 | `O(n^(3/2))`* | 依赖 gap | `O(n)` | `O(1)` | 否 | gap 序列决定 |
| 快速 | `O(n log n)` | `O(n²)` | `O(n log n)` | `O(log n)` | 否 | 随机化/三数取中 |
| 归并 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | 是 | 外排序基础 |
| 堆排 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)` | 否 | 原地、Top-K |
| 计数 | `O(n+k)` | `O(n+k)` | `O(n+k)` | `O(n+k)` | 可稳定 | 整数值域小 |
| 桶 | `O(n)`* | `O(n²)` | `O(n)` | `O(n+k)` | 取决于 | 分布均匀 |
| 基数 | `O(d(n+k))` | `O(d(n+k))` | `O(d(n+k))` | `O(n+k)` | 可稳定 | 定长位 |

* 带星号为依赖特定前提的渐进界，非普适 `O(n²)` 上限。

读表要点：**比较类七种受 `Ω(n log n)` 下界约束；非比较三种用额外信息换线性；稳定与否、原地与否直接决定选型。**

## 九、如何选型

把上面所有信息压成一张决策表，照着选基本不会错：

| 场景 | 首选 | 理由 |
| --- | --- | --- |
| `n` 很小（≤ 15）或近乎有序 | **插入排序** | 常数极小，近乎有序 `O(n)` |
| 通用、内存中、无稳定要求 | **快速排序**（三数取中 + 小数组插排） | 平均最快、原地 `O(log n)` |
| 需要稳定 / 最坏也要 `O(n log n)` | **归并排序** | 稳定、无退化 |
| 内存紧张、要原地且 `O(n log n)` | **堆排序** | 原地 `O(1)` |
| 求前 K 大/小 | **堆（Top-K）** | `O(n log K)` 不必全排 |
| 整数且值域不大 | **计数排序** | 线性 `O(n+k)` |
| 均匀分布的浮点 | **桶排序** | 期望线性 |
| 定长整数/字符串 | **基数排序** | 按位线性 |

语言内置一句话：

- **Java**：`Arrays.sort` 对基本类型用**双轴快排（Dual-Pivot Quicksort）**，对对象用**TimSort**（归并+插入的 Stable 混合）。
- **Python**：内置 `sorted`/`list.sort` 用 **Timsort**（稳定，归并思想的工程优化版）。
- **C++**：`std::sort` 通常是 **introsort**（快排 + 堆排 + 插入的混合，递归过深切堆排防退化）。

一句话记住：**没有"永远最快"的排序，只有"对当前数据特征最合适"的排序；工程实现几乎都是多种算法的混合体。**

## 本篇小结

- 排序是二分查找、归并、ORDER BY 等"有序才高效"操作的前置。
- **稳定性**指相等键保持原相对次序，多关键字排序必须依赖稳定排序。
- **比较排序下界 `Ω(n log n)`**（决策树 `2^h ≥ n!`）；要突破必须不比较。
- **冒泡/选择/插入**都是 `O(n²)`；插入对近乎有序接近 `O(n)`，小数据首选。
- **希尔**是插入的"缩小增量"改进，靠大跨步移动突破 `O(n²)`，gap 序列决定复杂度。
- **快排**分治 + partition 双指针，平均 `O(n log n)`、最坏 `O(n²)`，用随机化/三数取中/三路防退化，**不稳定**。
- **归并**先分后合、稳定、最坏也是 `O(n log n)`、需 `O(n)` 空间，是**外排序基础**。
- **堆排**建堆 `O(n)` + 取顶 `O(log n)`，原地 `O(1)`、最坏 `O(n log n)`、不稳定，是 **Top-K** 的根。
- **计数/桶/基数**是非比较排序，借整数/分布/位数信息达到线性 `O(n)`，但各有前提限制。
- **复杂度总表**把十种排序的均/最/好时间、额外空间、稳定性一表收口：比较类七种受 `Ω(n log n)` 下界约束，非比较三种凭额外信息换线性。
- **选型**看数据规模、是否近乎有序、稳定性、空间与分布；Java 用双轴快排/TimSort，Python 用 Timsort，C++ 用 introsort，工程实现多为混合体。
